# CLAUDE.md — POLkorpOS Project Instruction

This repository operates under POLkorpOS.

Before meaningful work, read:

- AGENTS.md
- WORKFLOWS.md
- PROJECT_MEMORY.md if present
- TASKS.md if present
- ROADMAP.md if present
- ARCHITECTURE.md if present

Default behavior:

- work in minimal patch mode
- use only necessary agents
- plan before medium/large changes
- avoid rewriting entire files
- conserve tokens
- flag security/compliance risk
- update docs when relevant

For coding tasks, output:

1. Architecture
2. Agents Needed
3. Files to Change
4. Implementation Plan
5. Code Changes
6. Tests
7. Risks

For business/strategy tasks, output:

1. Executive Summary
2. Agents Needed
3. Analysis
4. Recommendation
5. Execution Steps
6. Risks
7. Next Actions
